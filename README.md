# 社團動態

讓社團活動像 IG 貼文一樣被看見：一個入口看見全校活動、探索社團，並接著報名。

東吳大學 2026 第四屆「AI 時代：校園智慧創新」黑客松提案，團隊「問鼎東吳」。目前為提案階段，介面為示意設計，尚未實作上線。

## 要解決的問題

東吳有 137 個學生社團，各自經營 IG／FB 帳號。社團用心做的貼文，大多只觸及原本的追蹤者。

以漫畫學社的 IG 為例，從全校學生一路算到真正看到一篇貼文的人：

| 層級 | 人數 | 比例 | 依據 |
|------|------|------|------|
| 全校學生 | 14,715 | 100% | 大學問，114 學年學生數 |
| 有在用 IG | 約 11,478 | 78% | 資策會 MIC，18–24 歲 IG 常用比例 |
| 追蹤漫畫學社 | 332 | 2.3% | 漫畫學社 IG 粉絲數（含非東吳學生） |
| 看到一篇貼文 | 約 22 | 0.15% | 332 × 6.65%（Socialinsider IG 平均觸及率） |

學生天天在滑 IG，但一篇社團貼文只到得了全校約 0.15% 的人。

三方各自的痛點：

| 對象 | 痛點 | 需要 |
|------|------|------|
| 社團 | 曝光不均，流量低的社團更難被新生發現 | 觸及非追蹤者的管道 |
| 學生 | 要逐一追蹤社團帳號，常錯過報名時間 | 一處看到全校社團活動 |
| 學校 | 活動參與情形分散在各社團帳號，難以掌握 | 全校社團活動的參與數據 |

## 核心受眾

1. **優先：探索社團的東吳新生。** 還沒有固定的追蹤名單，希望找到適合自己的社團。平台讓他們不用逐一追蹤，也能發現感興趣的社團。
2. **後續：尋找單次活動的在校生。** 想參加講座、表演或體驗，但不一定想加入社團。平台讓他們依時間、校區與興趣找到可以報名的活動。

## 六個功能

| 功能 | 說明 |
|------|------|
| 推薦動態牆 | 依興趣、校區與截止時間，把貼文推給可能有興趣的同學 |
| 貼文卡片 | 活動時間、地點、截止日與報名鍵，一張卡片看完 |
| 探索社團 | 137 個社團依分類、校區搜尋，一鍵追蹤 |
| 社團主頁 | 社團介紹、近期活動與歷年貼文集中在一頁 |
| 收藏與提醒 | 收藏活動，截止前提醒報名 |
| 幹部帳號與數據 | 社長、社長代理人、公關長各自登入發文；查看曝光、收藏與報名點擊 |

貼文卡片照 IG 的閱讀習慣設計：社團名稱、海報與文案、活動資訊列、喜歡與收藏。

## 推薦機制

初期採可解釋的規則排序，先累積真實互動，再評估是否需要更進階的推薦模型。

1. **整理候選貼文**：只納入已上架、仍有效的活動；過期或取消的貼文不推送。
2. **計算排序訊號**：興趣符合度、校區便利性、活動時間、報名截止時間。
3. **排序並呈現**：較相關、較急迫的活動優先，同時保留不同社團與新貼文的曝光。

**冷啟動**：新使用者還沒有紀錄時，先混合近期活動、即將截止的活動與不同社團的貼文；有瀏覽、收藏、報名後再逐步調整排序。

設計參考 Facebook（Meta）News Feed Ranking 的多訊號排序概念。

## 報名與個資

台大、師大的社團系統都只提供社團介紹與行政申請，學生報名仍回到各社團自己的 Google 表單。本平台的做法：

- **平台不收敏感個資**：直接使用東吳電子化校園系統帳號登入。
- **報名名單留在社團端**：報名鍵連到社團自己的表單，平台只記錄「點了報名」。
- **數據只給統計值**：社團看得到曝光、收藏、點擊人數，看不到是誰。

## 社團帳號管理

- 每個社團一個官方主頁。
- 僅限社長、社長代理人與公關長登入發文，每人各自登入。
- 幹部交接時更換登入幹部，並保留歷年資料。
- 每篇貼文都記錄是哪位幹部發的；出問題時可依「貼文 → 發文幹部 → 所屬社團 → 平台管理員」追查處理。

## 營運規劃

| 階段 | 內容 |
|------|------|
| 啟動準備 | 建立社團資料、開通三位幹部帳號、匯入既有社團貼文 |
| 上線使用 | 在社團博覽會及新生第一哩宣傳平台，社團發布及更新活動 |
| 持續營運 | 平台維運：電算中心；社團資料：學務處／群美中心；權責確認：與學務處協調 |

利害關係人由內而外：

| 層級 | 對象 | 角色 |
|------|------|------|
| 使用端 | 學生、社團幹部 | 直接瀏覽、互動與發布內容 |
| 執行端 | 社團、平台維運 | 日常發文與平台維運 |
| 支持端 | 群美中心、學生會、總務處 | 協助社團博覽會與迎新推廣 |
| 政策端 | 校方行政單位 | 未來可提供社團名單與活動資料 |
